================================================================
         NUTRI&FORCE - Site E-commerce de Compléments
================================================================

DESCRIPTION DU SITE :
---------------------
Nutri&Force est un mini site e-commerce spécialisé dans la vente
de compléments alimentaires et produits de nutrition sportive.
Le site propose 5 catégories de produits :
  - Whey (protéines)
  - Gainer (prise de masse)
  - Créatine
  - Brûleurs de graisse
  - Multivitamines

STRUCTURE DES FICHIERS :
------------------------
devweb/
│
├── index.html          → Page d'accueil + filtrage produits
├── index.css           → Style de la page d'accueil
├── index.js            → Filtrage des produits par catégorie
│
├── inscription.html    → Formulaire d'inscription
├── inscription.css     → Style du formulaire d'inscription
├── inscription.js      → Validation inscription + localStorage
│
├── connexion.html      → Formulaire de connexion
├── connexion.css       → Style du formulaire de connexion
├── connexion.js        → Validation connexion + localStorage
│
├── achat.html          → Formulaire de commande/livraison
├── achat.css           → Style du formulaire de commande
│
└── readme.txt          → Ce fichier

INSTRUCTIONS D'UTILISATION :
-----------------------------
1. Ouvrir le fichier index.html dans un navigateur
2. Cliquer sur une catégorie pour afficher les produits
3. Cliquer sur "Acheter" pour accéder au formulaire de commande
4. Pour créer un compte : aller sur la page Inscription
5. Pour se connecter : aller sur la page Connexion
   (nécessite d'avoir créé un compte au préalable)

FONCTIONNALITÉS :
-----------------
  - Affichage dynamique des produits par catégorie (JavaScript)
  - Validation des formulaires côté client avec RegEx
  - Simulation d'authentification via localStorage
  - Site responsive (mobile, tablette, desktop)

TECHNOLOGIES UTILISÉES :
-------------------------
  - HTML5 (balises sémantiques)
  - CSS (Flexbox, responsive design)
  - JavaScript Vanilla (DOM, localStorage)
